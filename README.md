This program is a game written from scratch (appart from display drivers) to be run on an ESP32 with an Adafruit screen and simple button controllers.

Project was done for fun and also so I can try and apply some of my new coding and math knowledge.

The screen's setup can be changed, but the constants in the main.cpp file will need to be changed to suit your specific setup.
